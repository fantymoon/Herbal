## 为什么有这份清单

视频号以「尚未被现代科学证实或夸大功效」减少推荐。当时没有台账，所以既说不出哪几条被
投诉，也说不出哪几条还在视频号上公开。**两件事现在都能答**：平台导出已经导进每部影片的
台账，下面的表就是名单。

## 判罚的时间（由数据回填，不是回忆）

**生效在 2026-08-19 与 08-21 之间。** 08-19 菟丝子还有 1642 播放，08-21 起掉到 0–29，
之后再没恢复。完播率同期**没有变差**（木香 37.9%、车前子 31.8%）——低播放配正常完播率
正是「减少推荐」的形态：推荐被掐，内容本身没变。

所以那 33 部仍公开的旧片不是"内容还行、只是没量"，而是**账号仍在为它们付代价**。

## 证据

`npm run audit` 对每一部成片量三件事：每屏的阅读压力、有没有 `古籍称其主` 历史框定、
有没有 `此为汉代认知，未经现代科学证实` 那一行。结论：

- **55 部全部没有历史框定句，也全部没有那一行注释**——都是判罚之前的产物。
- **44 部用了「主治」**，现在这是禁用词。
- **52 部有某屏要求超过 15 字/秒**，其中 4 部超过 30 字/秒。30 字/秒以上，任何播放
  速度下都读不完。
- 现代疗效禁词（治疗 / 改善 / 有效 / 根治 / 特效 / 治愈 / 秘方 / 神效 / 必备 / 包治 /
  断根 / 奇效 / 立竿见影 / 药到病除）：**0 部**。

## 处置口径

| 处置 | 含义 |
| --- | --- |
| 私密 | 在视频号上转为私密。**一次性动作，优先做** |
| 私密·重制 | 转私密，并且按当前规范重做后替换 |
| 重制 | 不在视频号上，但某屏超过 30 字/秒，值得重做 |
| 留 | 维持现状。抖音未受影响，母版是唯一的资产 |

顺序是先平台后阅读压力：视频号上还公开着的，就是账号仍被平台据此评判的集合，下架是一次
性动作；而「主治」44 部都有、历史框定 55 部都缺，只有阅读压力能把它们彼此区分开。

## 建议的执行顺序

1. **先把视频号上那 33 部转私密。** 这是止血，不是"先查清再说"——判罚 08-21 就生效了，
   片子留着一天，账号就多被压一天。
2. **抖音 49 部不动。** 那边没有警告，而且在正常分发（09 月仍有 1000–4900 播放）。
3. 视频号在旧片清干净之前只发新规范的片（黄芝起）。新片合规是干净的，但权重能不能回来
   要看平台，别指望立刻恢复。
4. **私密·重制 那 2 部 + 重制 那 2 部**随后重做。丹沙的 2s 跳出率 41.1%、平均播放 5.2 秒，
   是全场最差。重制按 `publish-plan.md` 的顺序走，同一条目**先下架再替换**。
5. 麻黄（`ephedra-first-film`）两边都不在导出里，先确认它到底还在不在。

## 不要做

- 不要因为清单上有 55 行就批量下架。判罚只针对视频号。
- 不要重制后把旧片留着——同一条目两条视频会让账号看起来像搬运。
- 不要把这份清单当成发布排期。发布排期只看 `publish-plan.md`。
