## 为什么有这份清单

2026-09 视频号以「尚未被现代科学证实或夸大功效」减少推荐。当时没有台账，所以既说不出
哪几条被投诉，也说不出哪几条还在视频号上公开——**现在这一列补上了**：平台导出已经导进
每部影片的台账，下面的表就是名单。

## 证据

`npm run audit` 对每一部成片量三件事：每屏的阅读压力、有没有 `古籍称其主` 历史框定、
有没有 `此为汉代认知，未经现代科学证实` 那一行。结论：

- **55 部全部没有历史框定句，也全部没有那一行注释**——都是 2026-09 之前的产物。
- **44 部用了「主治」**，现在这是禁用词。
- **52 部有某屏要求超过 15 字/秒**，其中 4 部超过 30 字/秒。30 字/秒以上，任何播放
  速度下都读不完；这不是合规问题，是完播率问题。
- 现代疗效禁词（治疗 / 改善 / 有效 / 根治 / 特效 / 治愈 / 秘方 / 神效 / 必备 / 包治 /
  断根 / 奇效 / 立竿见影 / 药到病除）：**0 部**。

## 平台现状（来自导出回填）

- **49 部在抖音**，33 部在视频号，麻黄（`ephedra-first-film`）两边都不在——可能已删或
  早于导出窗口。
- 视频号流量在 **08-21 断崖**：之前每条 400–600 播放，之后掉到个位数；同期完播率反而
  不低（木香 37.9%、车前子 31.8%）。**是分发问题，不是内容问题。**
- 抖音 09 月这批仍有 1000–4900 播放，账号在抖音是健康的。

## 处置口径

| 处置 | 含义 |
| --- | --- |
| 留 | 维持现状。已发布影片是冻结的，当前规则不再回套 |
| 观察 | 先不动，但列入下一批重制候选 |
| 重制 | **先下架，再按当前规范重做，替换上线**。同一条目不能同时存在两条 |

处置列只看阅读压力，因为「主治」几乎人人都有、历史框定人人都缺，只有阅读压力能把它们
区分开。平台列是事实，两者合起来才是决定。

## 建议的执行顺序

1. **视频号上那 33 部**是真正要动的集合。抖音没有警告，49 部先不动。
2. 4 部「重制」优先（丹沙、麻黄、菖蒲、云母）。它们即使不被判罚，完播率也已经被阅读
   压力毁掉了——丹沙的 2s 跳出率 41.1%、平均播放 5.2 秒，是全场最差。
3. 麻黄两边都不在导出里，先确认它到底还在不在。
4. 重制时按 `publish-plan.md` 的顺序走，不要另起一套；同一条目**先下架再替换**。

## 不要做

- 不要因为清单上有 55 行就批量下架。平台只对视频号表过态。
- 不要重制后把旧片留着——同一条目两条视频会让账号看起来像搬运。
- 不要把这份清单当成发布排期。发布排期只看 `publish-plan.md`。
