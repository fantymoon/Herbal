## 为什么有这份清单

2026-09 视频号以「尚未被现代科学证实或夸大功效」减少推荐。当时没有台账，所以既说不出
哪几条被投诉，也说不出哪几条还在视频号上公开。这份清单把**能测的先测出来**，剩下的
留给你从创作者中心补。

## 证据

`npm run audit` 对每一部成片量三件事：每屏的阅读压力、有没有 `古籍称其主` 历史框定、
有没有 `此为汉代认知，未经现代科学证实` 那一行。结论：

- **55 部全部没有历史框定句，也全部没有那一行注释**——都是 2026-09 之前的产物。
- **44 部用了「主治」**，现在这是禁用词。
- **52 部有某屏要求超过 15 字/秒**，其中 4 部超过 30 字/秒。30 字/秒以上，任何播放
  速度下都读不完；这不是合规问题，是完播率问题。
- 现代疗效禁词（治疗 / 改善 / 有效 / 根治 / 特效 / 治愈 / 秘方 / 神效 / 必备 / 包治 /
  断根 / 奇效 / 立竿见影 / 药到病除）：**0 部**。

## 一个诚实的前提

清单里没有「平台」这一列，因为**不知道**。55 部发布时没有台账，抖音和视频号分别上了
哪几条已无从查证。「视频号上该私密哪些」这个问题只有创作者中心能回答。

## 建议的执行顺序

1. **先查视频号上还公开着哪些。** 那份名单才是真正要动的集合，其余先别碰。
2. 4 部「重制」优先。它们即使不被判罚，完播率也已经被阅读压力毁掉了。
3. 45 部「留」不要动。抖音没有警告，而 `out/` 里的母版是唯一的资产。
4. 重制时按 `publish-plan.md` 的顺序走，不要另起一套。

## 不要做

- 不要因为清单上有 55 行就批量下架。平台只对视频号表过态。
- 不要重制后把旧片留着——同一条目两条视频会让账号看起来像搬运。
- 不要把这份清单当成发布排期。发布排期只看 `publish-plan.md`。
