## 二、描述

```
《本草纲目》在「当归」这一条的释名里，一口气给了两种互相对不上的答案。

一种是典故：崔豹《古今注》说「古人相赠以芍药，相招以文无」，文无就是当归。
这个名字本身就是一句话——该回来了。

一种是药效：陈承说「能使气血各有所归，恐当归之名必因此出也」，
到明代卢之颐就把话挑明：「盖以功用为名矣。」

这一期把两条线排开：
· 这两种说法各自从哪本书来，语料里各有几部书在引
· 卢之颐那句断语，他自己也在前半截引了典故

引用的古籍：
《本草纲目》《证类本草》《本草乘雅半偈》《古今注》（《纲目》引）

本片为古籍文献展示，不构成医疗建议。
```

## 四、发布注意

- **封面不要用成片截帧**：信息流里封面只有约 200px 宽。
  横屏给 B 站 / YouTube，竖屏给抖音——**竖屏是重新排版，不是裁横屏**。
  `npx remotion still LongformDangGuiCoverH|V` 取第 0 帧即可，不用渲整片。
- **谱系图那屏的标题已写明「非考定的抄录关系」**，描述和旁白都不说「谁抄了谁」。
  七部书之间是「写过同一味药的名字」，不是「逐字传抄」。
- **弃用姜维那条**：「但有远志，不在当归」出自《三国志》，在语料里 **0 命中**。
  引文规则只许从语料复制，所以整条不用——它是这个故事最顺口的版本，也是最没有书证的版本。
- **结案句回答封面问题**：封面问「为什么叫当归」，结案说「一半是功用，一半是人事，
  书上没有给出唯一的答案」。这是正面回掉，不是一句俏皮总结。
- **配图**：`dried-angelica-slices-cc0.jpg`（Fumikas Sagisavas / Wikimedia Commons / CC0 1.0），
  已在 `public/images/credits.json` 登记。《当归》的**植株**照在这台机器上取不到
  （iNaturalist 的 `Angelica sinensis` 0 条），所以这一期只用饮片，不在画面上冒充鲜株。
