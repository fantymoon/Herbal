## 二、描述

### B 站 / YouTube

```
北宋的《证类本草》，在「蟹」这一条底下夹着一句话：
「妊娠人不得食螃蟹，令儿横生也。」

横生，是胎儿横卧腹中，难产里最凶险的一种。
这句话我们在七百零一部古籍里逐字检索，十九部书写过它——
最早引自唐代《杨氏产乳》，南宋进了《妇人大全良方》，
到明清，它和兔肉、雀肉排在一起，成了孕妇食忌里固定的一行。

这一期追两件事：
· 它从哪儿来，又怎么一步步固定下来
· 为什么偏偏是螃蟹——十九部书大多只说「不可」，不说「为何」；
  清初张璐把话说破了：「以其性专逆水横行也。」
· 以及民国《儿科要略》为什么写下「未可尽信」四个字

引用的古籍：
《证类本草》《杨氏产乳》《妇人大全良方》《证治准绳·女科》《本经逢原》《儿科要略》等十九部

本片为古籍文献展示，不构成医疗建议。孕期饮食请遵医嘱。
```

### 抖音 / 视频号

```
《证类本草》里写着「妊娠人不得食螃蟹，令儿横生也」。
这句话最早引自唐代，后来十九部医书写过它。
为什么偏偏是螃蟹？清初有人把话说破了：螃蟹横着走，孩子就横着生。
而民国一本书只回了四个字：未可尽信。

古籍文献展示，不构成医疗建议。
```

## 四、发布注意

- **封面不要用成片截帧**：信息流里封面只有约 200px 宽，成片的字号到那里就糊了。
  横屏封面给 B 站 / YouTube，竖屏封面给抖音 / 视频号——**竖屏是重新排版，不是裁横屏**。
- **谱系图那一屏的标题已经写明「非考定的抄录关系」**，描述和旁白都不要说「谁抄了谁」。
  十九部书之间是「写过同一句话」，不是「逐字传抄」。
- **平台匹配**：横屏 16:9 在抖音/视频号的信息流里会上下留黑边，
  如果主发这两个平台，优先用竖屏封面并考虑裁一版竖屏成片。
