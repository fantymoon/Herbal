## 二、描述

```
《神农本草经》白棘条（卷二·中经）里有四个字：「痈肿渍脓」。

这一集只查一个字。《名医别录》抄的《本经》原文写「溃」，《证类本草》写「溃」，
李时珍写「溃」，清人张璐也写「溃」——只有底本这一处写「渍」。

渍是浸泡，溃是溃破。痈肿不会浸出脓来；要排脓，得先溃破。
张璐把这一句解作「决刺破结」：刺能破开，脓才出得来。

照录原文，未改一字。实物照来自 iNaturalist（CC BY）。

古籍内容展示，不构成诊疗建议。
```

## 四、发布注意

- 合集挂「古书写错的字」，这是第四集（天雄「沥节痛」、败酱「疸痔」、百合「腹张」）。
  三集结论不同：前两集判讹字，第三集（百合）判古今字，**这一集回到讹字**，
  但理由要说清——不是「底本写错了形近字」，而是「渍」在这个句子里不成话。
- **判据**：`npm run variants` 报这一条是 0 : 6，底本那一读法全库没有第二处作证。
  另外三条他本（别录、证类、纲目、逢原）逐字一致——四处对一处。
- **引文逐字核过**：底本见 `000-神农本草经.txt` 白棘条（卷二·中经，27 字，无缺字）；
  「痈肿溃脓」见 `050-名医别录.txt`（标注为「《本经》原文」）、
  `645-证类本草.txt`、`013-本草纲目.txt` 木部白棘条【主治】、
  `019-本经逢原.txt` 白棘条。
- **配图**：白棘＝酸枣树针（《证类本草》引李当之「此是酸枣树针」）。
  iNaturalist 的 `Ziziphus jujuba spinosa` 是酸枣的变种名，三张都按 `--fruiting` 筛过，
  果实都在画面里。单味药线没有做过白棘，不与他片重复。
- **下一集是天名精**（新合集「一条药，三个名字」的第一集）：「一名麦句姜，一名虾蟆蓝，
  一名豕首」三个别名各有一处来由。已在单味药线同日做成 15 秒短片，本集是它的问答版。
