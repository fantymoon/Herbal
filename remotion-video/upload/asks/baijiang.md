## 二、描述

```
《神农本草经》败酱条：「主暴热火创、赤气，疥瘙，疸痔，马鞍热气。」

这一集只做一件事：把这一个字的来去查清楚。
《名医别录》抄的《本经》原文写「疽」，《证类本草》写「疽」，
李时珍写「疽」，还特意注明这一句出自《本经》——只有底本写「疸」。

疸是黄疸，疽是深部的疮。「疥瘙」是皮肤病，和它并列的本该是「疽」。

照录原文，未改一字。实物照来自 iNaturalist（CC BY）。

古籍内容展示，不构成诊疗建议。
```

## 四、发布注意

- 合集挂「古书写错的字」，这是第二集（第一集：天雄「沥节痛」）。
  这一集的素材同样来自 `npm run variants` 的产出。
- **片内没有改字**：屏幕上照录底本的「疸痔」，异文放在「考」屏对读。
- **引文逐字核过**：底本见 `000-神农本草经.txt` 败酱条（卷二·中经）；
  「主暴热火疮赤气，疥瘙疽痔，马鞍热气」见 `050-名医别录.txt` 败酱条
  （该文件标注为「《本经》原文」）与 `645-证类本草.txt` 败酱条；
  《本草纲目》见 `013-本草纲目.txt` 败酱条【主治】。
- **同一个讹字在萹蓄条里也出现**（底本「浸淫疥瘙，疸痔」／证类「浸淫疥瘙疽痔」）。
  这一集只讲败酱，萹蓄留给以后——**判据：一集只做一个字，多讲一处就讲不透。**
- **配图**：`Patrinia scabiosaefolia`，iNat 记作 `PATRINIA SCABIOSIFOLIA`
  （拼法差一个字母，同一个种），四张都是横构图，正好给物屏的横框。
- **下一集是百合**（古书写错的字 03）：「腹张」对「腹胀」。
  但那一集的结论和这一集相反——**那不是写错，是古人还没把「张」「胀」分开**，
  所以下一集的问题要写成「为什么不算错字」，不能照抄这一集的说法。
