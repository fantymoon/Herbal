## 二、描述

```
《神农本草经》百合条：「味甘，平。主邪气腹张，心痛，利大小便，补中益气。」

这一集的结论和上一集相反：这个「张」不是抄错的。
《名医别录》抄的《本经》原文写的也是「张」；到宋代《证类本草》才改成「胀」，
李时珍也写「胀」，还注明这一句出自《本经》。
可一千多年后，清代的《醉花窗医案》里还在写「转增腹张」——
如果这是抄手写错，它不会在一本毫不相干的医案里再出现一次。

「张」是旧的写法，「胀」是后来分出来的字。那时候，古人还没把这两个意思分开。

照录原文，未改一字。实物照来自 iNaturalist（CC BY / CC0）。

古籍内容展示，不构成诊疗建议。
```

## 四、发布注意

- 合集挂「古书写错的字」，这是第三集（天雄「沥节痛」、败酱「疸痔」）。
  前两集的结论都是"底本错了"，**这一集不是**——所以问题写成「为什么不算错字」，
  不能照抄前两集的说法，否则第三集会像前两集一样收在一个错的结论上。
- **判据（这一集的方法）**：底本与证类不一致时，先看**有没有第二个抄本支持底本**。
  百合这一条，《名医别录》抄的《本经》原文也作「张」——两处对一处，那就不是孤证，
  再看清代的用法（《醉花窗医案》「转增腹张」），就能判成古今字而不是讹字。
  `npm run variants` 报的 1 : 5 就是这个信号：**「1 处」不是噪音，要看那 1 处是谁。**
- **引文逐字核过**：底本见 `000-神农本草经.txt` 百合条（卷二·中经）；
  「主邪气腹张……」见 `050-名医别录.txt` 百合条（标注为「《本经》原文」）；
  「主邪气腹胀……」见 `645-证类本草.txt` 百合条；
  《本草纲目》见 `013-本草纲目.txt` 百合条【主治】；
  「命服地黄汤，转增腹张」见 `678-醉花窗医案.txt`。
- **配图**：`baihe-flower` 的观察者鉴定是 `Lilium brownii viridulum`，
  是 Lilium brownii 的**变种**，同一个种，所以 ⚠ 是变种级差异，不是配错；
  其余三张 CC0，鉴定为 Lilium brownii。
  单味药线的百合片用了 `lilium-brownii-baihe.jpg`，这一集不重复用它。
- **下一集是白棘**（古书写错的字 04）：「痈肿渍脓」对「痈肿溃脓」。
  底本 27 字无缺字，已核实；配图需要另行确认（白棘＝酸枣树针，见《证类》引陶隐居）。
