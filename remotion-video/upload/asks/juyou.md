## 二、描述

```
《神农本草经》「橘柚」条的末尾写着：「一名橘皮。」

这一集只做一件事：把这一对药名的来历追清楚。
宋代的寇宗奭说，橘和柚本来就是两种，《本草》只写了「一名橘皮」，
是后人误加了「柚」字；到明代，李时珍把柚单独立了一条。

照录原文，未改一字。实物照来自 iNaturalist（CC0 / CC BY）。

古籍内容展示，不构成诊疗建议。
```

## 四、发布注意

- 竖屏投稿，不要投成横屏留黑边。底部 25% 是平台 UI 区，片内没有放字。
- 合集挂「厨房里的本草」。上一集（大枣）的预告指向本集，**先确认本集已就绪再发上一集**。
- 引文逐字核过上下文：本经「一名橘皮」在 `000-神农本草经.txt`；寇宗奭语见
  `013-本草纲目.txt` 橘条；纲目另有独立的「柚」条。
- **配图只有柚的叶**：开放数据通道里 `Citrus maxima` 的观察全是营养器官（叶、干）；
  搜「Citrus reticulata」返回的果实照经核对，观察者鉴定为 `Citrus × aurantium`（酸橙），
  不是橘——那两张已删。所以「物」段讲的是芸香科的翼叶（箭叶），这是名物特征，不是凑数。
  要换成「橘果 + 柚果」的画面对，得先有能核实到种的图源。
