# 本草一问

**每集 40 秒，答一个你想问但没人讲过的本草问题。**

讲**名物、文字、历史**，不讲功效。古书里的功效句只作为带出处的原文出现在画面上，
旁白从不复述——合规靠样式本身保证，不靠事后审词。

差异化资产：700 部古籍可以做**跨书对读**。同一味药从《本经》到《证类》再到《纲目》，
说法怎么变、字怎么写错，这是别的账号做不了的。

平台：B 站，竖屏 1080x1920。

---

## 单集结构（35–45 秒，时长由旁白决定）

| 段 | 画面 | 干什么 |
| --- | --- | --- |
| **问** `ask` | 全幅实物照 + 大字问题 | 第 0 帧即封面。问题必须能独立成图 |
| **物** `object` | 2–3 张实物照慢推切换 | 它今天是什么、你在哪见过它 |
| **书** `book` | 宣纸底竖排原文，读到哪个字哪个字朱红 | 只读与问题相关的那一两句 |
| **考** `study` | 唐/宋/明的书对读，最后一条是答案 | 异文、注家分歧、名字由来 |
| **收** `closing` | 盖印 + 下集预告 + 小字免责 | 固定收尾 |

五段的顺序由 `ASK_ROLES` 固定，缺一段或换顺序，`ask:build` 直接报错。

## 视觉语言

- **三色**：宣纸米 `#efe6d3`、墨黑 `#17140f`、朱砂红 `#b93a2b`。
  每个部类另加一个辅色（草部青 `#4a6b5a`、果部赭 `#a5613a`、石部灰蓝 `#4a5a6b`）。
- **三种镜头**：微距实物 → 古书竖排 → 对读。每集都按这个节奏走，形成辨识度。
- **竖排古文加横排字幕**。古文是画，字幕是话。
- **转场只有一种**：墨晕开（`InkReveal`，一个扩张的圆形遮罩，不是素材）。
- **印章标记章节**：一段一个字（问 / 物 / 书 / 考 / 收）。
- **底部 25%（y > 1440）留给平台 UI：放画面，不放字。**

## 系列封面

单集用**第 0 帧**当封面（问题与实物照都在那一帧上）。系列层面另有一张：

```bash
npx remotion still AskSeriesCover out/asks/covers/bencao-yiwen-cover-v.png
```

大字位置给的是系列名，不是任何一味药——拿一集的果子当整个系列的门牌，会把系列读成一集。
实物照退到底部那条画面带里，选的是全株藤叶而非任何一集的答案，因为那 480px 是平台 UI 区，
**放画面不放字**（与渲染器同一条线）。

文案与几何在 `src/asks/series-cover.ts`（渲染器 `series-cover-film.tsx` 只负责画它），
由 `seriesCoverProblems` 判五件事：系列名在场、措辞不越功效词与账号定位词、免责声明在场、
任何一行的底边不出 y=1440 且宽度不顶出内容列、那张照片在 `credits.json` 里且署名与台账逐字一致。
前两条是判断，后三条是量出来的——`tests/ask.test.ts` 用坏输入验证它们真的会变红。

那行「七百部古籍做底」说的是语料库（`TCM-Ancient-Books-master/` 下 701 个文件），
不是已经引过的书数：五集实际引到 10 部，下面列的三部只是对读主干（本经 → 证类 → 纲目）。
所以它不能写成「三部书」——那会把做过的事说小，而观众只会照字面读。
这句关于账号自己的事实有一条测试数着语料库的文件兜底，语料哪天缩到 700 以下它就会红。

## 制作管线

```bash
cd remotion-video

# 1. 写一集：asks/<id>.yaml（唯一的正文来源）
# 2. 编译成渲染器可读的静态模块
npm run ask:build

# 3. 合成旁白（词级时间戳）+ 编译配音模块
npm run ask:voice -- --id=<id>          # 已有音频会跳过；改了旁白要 --force

# 4. 生成 Composition 注册表（从 src/asks/ 扫，所以「加一集」就是加一个 YAML）
npm run ask:compositions

# 5. 三条规则
npm run ask:check -- --id=<id> --verbose

# 6. 渲染 + 容器断言（全部集，或 --id=<id>）
npm run ask:verify -- --render
```

加一集的完整步骤就是：放一个 YAML、跑 2→4。注册表是生成的，CI 会检查它与 `src/asks/` 同步。

**配图先核实到种再登记**：`npm run fetch-photo -- --taxon=… --check` 现在会把**观察者自己的鉴定名**打出来（与搜索用的属名不同时会标 ⚠）。这一条是踩出来的——搜「Citrus reticulata」返回的果实照，观察者鉴定是 `Citrus × aurantium`（酸橙），
不看这一行就会给一集讲橘柚的片子配上酸橙。

**为什么中间要编译一次**：Remotion 的组件必须是纯函数，不能运行时读文件。
YAML 是给人写的，TS 是给渲染器读的——这和跨书专题系列把旁白时长编译成
`src/topics/<id>.voice.ts` 是同一条约定。

**为什么时长在构建期算、不用 `calculateMetadata`**：旁白必须先合成出来，时长才存在，
而 `calculateMetadata` 跑在渲染时、合成不了音频。结果一样（时长由旁白决定），
而且渲染时不需要网络。

## 词级时间戳

`edge-tts --write-subtitles` 给的是**句级** SRT——一段 8 个字的古文只会回一条整句边界，
一个字都落不下来。所以 `scripts/tts_words.py` 直接消费 WordBoundary 事件流：

```python
edge_tts.Communicate(text, voice, proxy=PROXY, boundary="WordBoundary")
```

`boundary` 默认是 `"SentenceBoundary"`（7.x 起改的），**必须显式要词级**。

`ask-voice.ts` 再把边界摊平成 `charTimes`（第 i 个汉字在何时被读出）和
`quoteTimes`（引文每个字的读出时刻）。「书」屏的逐字朱红靠的就是后者。

**对齐靠一条不变式**：边界里的 `text` 是归一化后的文本，把它们首尾相接，
正好等于旁白去标点后的字序列。对不上就报错——一屏朱红推进错了位，比不亮更难发现。

**「书」屏摆的是整段原文，旁白可以只读其中一句。** 引文的哪个字开始亮，由 `read`
在引文里的位置决定，所以 `read` 必须**同时**是旁白与引文的连续子串——`ask:build`
两头都核（少核一半，朱红就会从引文的第一个字开始亮、亮到 read 用完为止，整体错位）。
`dazao-ye` 与 `wangbuliuxing` 读的是整段（偏移 0），`juyou` 读末尾四个字、
`tianxiong` 读中间三个字——两种情形都在生产里跑过。

## 三条门禁（`npm run ask:check`）

1. **旁白与字幕里不出现功效词**——扫问题、旁白、考据小注、预告，以及台账的
   标题/描述/话题。**引文豁免**：那是书上说的，平台反对的是"我们替古人下结论"。
2. **每条引文都有出处**。
3. **每张图都有授权**——`public/images/credits.json` 里登记过且许可非空，
   片内署名由 `ask:build` 从台账烘进来（两处各存一份就会各说一套）。

外加一节 **sync**：YAML 与 `*.content.ts`、旁白与 `*.voice.ts` 是否同一版。
它不判内容，只判"你手上的东西是不是同一版"——改了旁白没重新合成，
三条内容规则一条都不会响，但片子会声画脱节。

## 还没做的

- **字体**：全片只嵌霞鹜文楷（SIL OFL 1.1，可商用）。字幕本想用黑体，
  但系统黑体在 Windows 上有、Linux 上没有，同一份内容会渲染出两种片子
  （这个仓库为此已经付过 24MB 字体代价，CI 也跑在 Linux 上）。现在用
  `-webkit-text-stroke` 描边增重，可移植但不如黑体易读。要改就得嵌一款可商用的黑体。
- **木刻药图**：设计里「书」屏要叠一张木刻药图，目前没有这个通道。
  `public/plates/` 只有《饮膳正要》的书影，与本系列的书对不上。
- **书影**：「考」屏设计里要三本书书影并排，现在渲染的是文字对读。
  要书影得先有《千金翼方》《证类本草》《本草纲目》的可授权影印本。
- **矿物类做不了**：「古人吃的石头」那一集需要矿石实物照，而矿物图源
  （mindat、Smithsonian、Wikimedia Commons、BHL）在这台机器上全部 403 或超时。
  iNaturalist 只有生物，没有矿物。
- **纸纹**：`书`屏现在的纸纹是 CSS 渐变画的。单味药线那边在做一张程序生成的
  纸纤维贴图（`public/textures/paper-fibre.jpg`，无扫描、无出处问题），做完了可以共用。
- **合集**：「名字古怪的药」「古书写错的字」各起了头；「同名不同物」还没有内容；
  收尾只预告了下一味药，还没导向长视频线（`src/topics/`）。
