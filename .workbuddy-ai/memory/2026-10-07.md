## 执行的三项

### 1. 封面不再依赖 hook（真 bug）

`openingFor` 改成 `kinds.includes("heroTitle")`——**判据是「这一屏有片名」，不是「文案里有 hook」**。
大枣第 0 帧现在是一张正经封面（渲出来看过）。

### 2. 内嵌霞鹜文楷（OFL 1.1，可商用）

- `public/fonts/LXGWWenKai-Regular.ttf`，24.4MB，来自 GitHub release v1.522。
- `@remotion/fonts` 的 `loadFont`，在 `src/index.ts` 里加载。**必须装 4.0.506**，
否则 Remotion 报版本不匹配直接不出片（踩过）。
- 字体栈改成 `'LXGW WenKai', STKaiti, KaiTi, serif`。
- **副作用：霞鹜文楷的中文字宽是 1em，华文楷体更宽**，所以药名现在占 74% 宽而不是之前的 94%。
  `wrappedLineCount` 用 `width / fontSize` 估字数，本来就是按 1em 算的——**换字体让版式计算变准了**。
- 24MB 进仓库。仓库已 342MB（语料 164 + 图片 128），这是「片子长什么样不该取决于哪台机器渲染」的代价。
